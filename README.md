# Проект 'Сервис управления рассылками'

## Описание 
Веб-приложение, которое позволяет пользователям управлять рассылками сообщений для клиентов.
Приложение включает функциональность для  создания, просмотра, редактирования и удаления рассылок, а также
отправки сообщений по требованию.

## Технологии
- **Backend**: Django 6.0
- **Frontend**: HTML5, CSS3, Bootstrap 5
- **Package manager**: Poetry
- **Version control**: Git + GitFlow
- **Python**: 3.13+
- **PostgreSQL**
- **Redis**
